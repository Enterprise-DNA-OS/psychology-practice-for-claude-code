# Weekly review

Run `attention`, `referrals-due`, `debtors` and `outcomes` through `node scripts/practice.mjs`. Write the Monday review into `drafts/weekly-review-YYYY-MM-DD.md`: missing notes, courses to renew, GP reports, balances by currency and overdue measurement reviews. Assign decisions to the responsible practitioner, not a diagnosis. Include the query date. Never send.
