# Customise

Read the schema and docs/compliance.md. Clarify the requested field, label or practice policy using existing records. Write the next numbered migration without rewriting an applied migration. Preserve historical records. Update the CLI, command and renderer that use it. Apply with `npm run migrate`; run `npm test` in the isolated test database. Show the operator the changed example. Never weaken a cited funding rule without a current authoritative source. Never apply to another database or change a production privacy control without the operator's authority.
