# Why no front end

Your practice owns the database. Claude Code, Codex, OpenCode or Cursor reads and updates it through the same CLI. Weekly questions join the diary, funding, notes and unpaid invoices without waiting for a vendor to add a report.

A screen offers faster visual diary scanning, drag-and-drop bookings, mobile entry, offline access and patient self-service. This base provides none of those. Generated HTML dashboards are read-only files, not an authenticated portal. An operator runs the commands or describes the task to an approved agent.

Enterprise DNA can build a desk screen, a booking portal, reminder connections or another stack around the practice's rules. Scope and validate those integrations before replacing a service that depends on them. Free software still needs a host, backups, maintenance and an approved agent service.
